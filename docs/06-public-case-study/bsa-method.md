# BSA method

1. Freeze the release candidate identity, version, window and change scope.
2. Define mandatory readiness gates before reading the outcome.
3. Bind each gate to evidence, owner, issuer, dates and approval state.
4. Validate manifests, hashes, identity, dates and cardinality.
5. Evaluate each gate independently.
6. Apply strict decision precedence.
7. Separate failed gates from evidence blockers.
8. Preserve waivers and residual risks explicitly.
9. Bind the packet to a canonical SHA-256 digest.
10. Require one-use human review against that digest.
11. Export a challengeable decision record.
12. Reassess whenever evidence, policy or candidate identity changes.

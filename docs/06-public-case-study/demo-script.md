# Five-minute demonstration script

## 0:00–0:45 — Decision problem

Show the three outcomes. Explain that missing evidence is not failure, and
failure is not uncertainty.

## 0:45–1:30 — Frozen cases

Open the PASS, BLOCKED and FAIL evidence packs. Highlight candidate/version
binding and file manifests.

## 1:30–2:30 — Blocked case

Run the blocked scenario. Show G-11 stale, G-13 missing, and G-14 pending. Point
out that no score can hide those blockers.

## 2:30–3:15 — Fail precedence

Run the fail scenario. Show that explicit security and rollback failures produce
FAIL even though twelve gates pass.

## 3:15–4:10 — Human review

Create a run, issue a one-use challenge, confirm the packet, and verify the
hash-linked ledger.

## 4:10–5:00 — Exports and limitations

Open JSON, Markdown and standalone HTML. Show the common snapshot digest and the
authority banner. Close by stating that the case is synthetic and no deployment
is performed.

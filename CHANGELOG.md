# Changelog

## 0.1.0 — Complete public case study

- froze PASS, BLOCKED and FAIL synthetic release-readiness scenarios;
- added fourteen mandatory evidence-bound readiness gates;
- implemented strict `FAIL > BLOCKED > PASS` precedence;
- added freshness, approval, identity, cardinality and waiver controls;
- added provider-neutral advisory verification;
- delivered CLI and Streamlit Decision Room workflows;
- added digest-bound human review and hash-linked SQLite events;
- added equivalent JSON, Markdown and safe HTML exports;
- added evaluator-isolated metrics and adversarial tests;
- added Python 3.12/3.13 CI and complete security/package gates;
- published the visual public case study and reproducible demo.

The release performs no production deployment, risk acceptance, release-window
approval, or real go-live authorization.
